# Public Portfolio Sanitization Standard

All examples in this repository use generic terminology and must not include:

- employer/client-specific table or column names
- production URLs, tenant IDs, environment IDs, or real GUIDs
- secrets, tokens, certificates, API keys, connection strings, or passwords
- PII, PHI, or confidential business data
- proprietary solution exports, screenshots, or source code that is not authorized for publication

Generic examples use neutral names such as `demo_request`, `demo_configuration`, `Customer`, `Program Period`, and `Service Area`.
